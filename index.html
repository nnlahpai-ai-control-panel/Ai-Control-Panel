GPU pools

Split your cards into groups, e.g. AI for llama.cpp/Ollama and Media for Jellyfin/Immich. Then pick a pool in AI Models or when installing an app. No pool = all GPUs.

GPU hot plug and auto rebalance

The panel checks your GPUs every 5 seconds. When a card is added, removed or drops off the bus, llama.cpp and Ollama are restarted and the model is re-split across the GPUs you have now.

🌿 GPU eco mode

Cap how much power the GPUs may draw. LLMs mostly wait on memory, so Eco usually costs only a little speed while cutting power and heat a lot. The setting is applied again after every reboot.

🤖 AI assistant

        
The 💬 button (bottom right) and the Telegram bot use this model to answer questions, read logs, and propose actions like installing apps or making a video. Nothing changes until you press the confirm button. It works best with a model that supports tools, such as qwen3:8b. Without a model it still understands simple commands like "install jellyfin".

        

          
          
          
          
        

        

      

      

        

          
👥 Users and roles

            
Admin can do everything. User only sees the apps you tick, and can open, start, stop, restart, update and read logs for them. Users can't install apps, use the terminal or files, or see the GPU and system pages.

          
        

        

      

      

        

          
🌐 Domains and automatic HTTPS

            
Give the panel or any app its own address like chat.example.com. A free Let's Encrypt certificate is issued and renewed for you. Point the domain's DNS (A record) at this server and forward ports 80 and 443 on your router.

          
        

        

        
No public IP or can't open ports? Use Cloudflare Tunnel from the App Store instead. For names only used at home (like nas.lan), choose "Local network" and the panel makes its own certificate.

      

      

        
🛍️ App store sources

        
Add more app catalogs by URL: your own GitHub repo, a friend's, or a community list. The file uses the same format as apps_catalog.json. A GitHub repo link works if the repo has apps_catalog.json at the top. Only add sources you trust, because apps run as Docker containers on this server.
